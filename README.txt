# Bình Mỹ Moon River Resort

Front-end demo only.

## Cấu trúc
- index.html
- css/style.css
- js/script.js
- images/

## Chạy trên Linux
Mở Terminal trong thư mục project:

    cd binh-my-moon-river
    xdg-open index.html

Hoặc dùng VS Code + Live Server.

## Thay ảnh
Các ô ảnh hiện là placeholder. Sau này đặt ảnh thật vào thư mục images/ với các tên:
hero.jpg, resort.jpg, river.jpg, room.jpg, garden.jpg, meditation.jpg,
wellness.jpg, therapy.jpg, farm.jpg, cow.jpg, food.jpg, activities.jpg.

## Lưu ý
Đây là website front-end. Booking demo được lưu bằng localStorage, chưa có backend,
thanh toán, database hay hệ thống đặt phòng thật.
